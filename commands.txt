STEPS to create the project(movie ticket reservation and seat locking system)
=================================================================================

1) Create the project folder  --> (MovieTicketSystem)

2) Open the command prompt (cmd)

3) Create the Environment --> (python -m venv myenv)

4) Activate the Environment --> (myenv\Scripts\activate.bat)

5) Check the python version --> (python --version)

6) Check the pip --> (pip --version)

7) Update the pip --> (python -m pip install --upgrade pip)

8) Install the Django --> (python -m pip install django)

9) Check the installation of the Django --> (django-admin --version)

10) Install the MySQL Driver --> (python -m pip install mysqlclient)

11) Create the Django Project --> (django-admin startproject ticket_project .)

12) Create the APPs --> (django-admin startapp accounts)
                         (django-admin startapp movies)
                          (django-admin startapp bookings)

13) Create the Templates Folder --> (templates)

14) Create the HTML files in Templates folder in VS Code --> (accounts.html,movies.html,bookings.html)

15) Create the Static Folder --> (static)

16) In Static Folder Create the Three Folders --> (CSS,images,js)

17) Create the files in CSS --> (accounts.css,movies.css,bookings.css)

18) Create the files in Apps (urls.py) in Three apps

19) In VS Code We Register the apps in settings.py in ticket_project --> INSTALLED APPS=[ 'accounts','movies','bookings',]

20) Configure the Templates In Settings.py in ticket_project --> 'DIRS':[BASE_DIR/'templates'],

21) Configure the Static in settings.py in ticket_project --> STATICFILES_DIRS=[BASE_DIR/'static']

22) Run the Django migration in CMD prompt --> (python manage.py migrate)

23) Check the project --> (python manage.py check)

24) Run Server --> (python manage.py runserver)
